# Sapere Logistica

Sito saperelogistica.it: la professione logistica, spiegata bene.
Glossario con fonti ufficiali, rassegna settimanale, corso di aggiornamento (non di certificazione).

Sorgenti in `_src/` (Markdown + template Jinja). Generazione: `python3 _src/build.py`.
L'HTML generato nella radice è quello che Hostinger pubblica. Regole editoriali in `_src/piano-editoriale.md`.
